# Correspondência individual de palavras-chave

Este pacote atualiza o serviço privado de criação de campanhas para interpretar, por linha, `[termo]` como exata, `"termo"` como frase e termo sem marcadores como ampla, tanto para palavras positivas quanto negativas. Chamadas antigas continuam aceitas com seus tipos globais.

## Instalação

O pacote está preparado localmente e não foi publicado. Faça backup do serviço instalado e substitua somente o arquivo [google-ads-campaign-action-service.php](hostinger-private-tools/google-ads-campaign-action-service.php) no destino privado:

```text
/home/u572283517/domains/travenzo.shop/domains/travenzo.shop/private-tools/google-ads-campaign-action-service.php
```

O arquivo deve permanecer fora de `public_html`. Não envie este README, credenciais, configurações ou outros arquivos. Não há alteração de SQL ou configuração. Instale o serviço antes de utilizar a prévia da nova interface: a versão antiga recusa a nova solicitação.

Depois da instalação, confira os tipos e termos na prévia do Hub usando palavras de cada tipo, inclusive negativas. A prévia não cria campanhas. Revise-a antes de qualquer criação de campanha.
